## 1. 产品愿景与定位 (Vision & Value Proposition)

AI Reader 核心计算与智能解析引擎（AI Reader Core Engine）定位于**高性能文档解构、离线概念图谱拓扑计算、认知伴读流式编排与跨端 FFI 协议调度**的底层计算基础设施。

作为纯核心计算与解析引擎，AI Reader 解耦具体的图形呈现层（GUI/Flutter），专注于提供标准化、高吞吐、零外部网络依赖的本地文档认知中台：
- **全格式统一结构化解析**：无论 PDF、EPUB、Markdown 还是 TXT，统一解构为结构化 Document AST 语义流；
- **空间感知与原版坐标保留**：在提取正文段落的同时，保留物理页码、章节层级与坐标锚点，为上层集成提供精准溯源依据；
- **深度认知伴读管道**：内置 4 大认知伴读模板（通俗化、逻辑链、批判性、术语拆解）与流式 LLM 上下文装配管道，支持离线启发式降级；
- **离线概念拓扑与导图生成**：纯本地全量三级 NLP（全文/章节/句子）关键词抽取（TF-IDF + TextRank）与 PMI 概念共现拓扑，并自动生成结构化知识导图树；
- **本地高可靠持久化**：基于 SQLite WAL 模式，管理书籍元数据、章节切片、关键词拓扑、批注与问答历史；
- **双模访问接入**：提供标准 CLI 命令行工具与标准化六元组 C-ABI FFI 桥接协议，支持第三方图形界面、终端脚本与自动化流水线即插即用调用。

## 2. 目标用户与使用场景 (Target Users & Scenarios)

### 2.1 目标用户画像
1. **知识工程师 / 数据科学家**：
   - 核心诉求：本地自动化批量解析长篇技术文档、论文和规范，批量抽取概念拓扑、核心词与知识树，沉淀为知识图谱。
2. **终端命令行与高级开发者**：
   - 核心诉求：在无图形界面（Headless/SSH/Docker）的服务器或开发环境下，通过命令行快速检索、解析文档并调用 AI 伴读分析。
3. **上层应用架构师 / 客户端开发者**：
   - 核心诉求：将 AI Reader 作为原生动态库（`.so`/`.dll`/`.dylib`）或独立服务嵌入任意上层 UI 框架（Web、Desktop、Mobile），免去重新实现解析与 NLP 的成本。

### 2.2 核心业务场景与操作链路
- **场景 1（文档批量导入与 AST 解构）**：调用 `doc.parse` 导入文档 -> 自动路由至对应格式解析器 -> 提取元数据、章节与句子节点 -> 写入本地 SQLite 存储。
- **场景 2（全书离线 NLP 与概念拓扑计算）**：调用 `nlp.keyword_extract` 与 `graph.build` -> 离线分词打分 -> 生成多级关键词网络与 PMI 概念关联拓扑。
- **场景 3（思维导图知识树提取）**：调用 `mindmap.generate` -> 结合目录 AST 与主题词抽取生成层级思维导图树。
- **场景 4（认知伴读流式分析）**：调用 `ai.companion_ask` -> 装配段落上下文与指定认知模板 -> 流式输出深度洞察（离线模式自动降级为确定性思维启发卡）。
- **场景 5（批注增量管理与导出）**：调用 `annotation.save` / `annotation.list` -> 增量存取高亮与段落笔记 -> 支持导出标准化 Markdown 笔记。

## 3. 功能矩阵规格说明 (Feature Matrix & Functional Specs)

| 模块编号 | 功能模块 | 核心能力描述 | 关键性能与接口指标 |
|---|---|---|---|
| **F-01** | **全格式统一解析引擎** | 统一支持 PDF、EPUB、Markdown、TXT 格式；解构为统一 Document AST，提取章节、段落、样式与嵌入媒体信息。 | 10 万字文档冷启动解构 < 1.5 秒；内存占用 < 50MB。 |
| **F-02** | **结构化段落分块与空间定位** | 将文档文本切分为章节与句子节点；精确记录段落索引、页码跨度与字符偏移量。 | 准确率 100%；支持大文本流式惰性切片。 |
| **F-03** | **批注与边注数据管理** | 支持段落锚点绑定、颜色标识、样式类型、笔记正文及关联 AI 伴读内容的持久化存储与检索；支持 Markdown 格式笔记导出。 | 原子事务写入；100% 增量保存无数据丢失。 |
| **F-04** | **深度认知伴读与模板编排** | 4 大认知伴读模板（通俗化、逻辑链、批判性、术语拆解）；流式组装上下文，支持指数退避重试与离线启发式降级。 | TTFT < 800ms；离线降级响应 < 10ms。 |
| **F-05** | **离线三级 NLP 概念图谱计算** | 本地离线全量计算：全文级/章节级/句子级关键词提取（TF-IDF + TextRank）；词间共现矩阵与 PMI 关联分析。 | 纯本地离线计算，零外部 API 依赖；10 万字图谱构建 < 200ms。 |
| **F-06** | **结构化知识导图生成** | 结合文档目录 AST 与章节级核心词，自动提取全书知识树与多级导图节点。 | 节点秒级生成，提供标准树状 JSON 数据结构。 |
| **F-07** | **本地持久化与 WAL 事务** | 基于 SQLite 数据库；记录书籍元数据、章节、句子、关键词拓扑、思维导图、批注与问答历史；支持审计字段与版本并发控制。 | WAL 模式；零网络依赖；崩溃自恢复。 |
| **F-08** | **CLI 命令行与六元组 FFI 接口** | 提供跨平台终端 CLI 工具（`ai_reader`）与统一信封格式的 C-ABI FFI 函数 `ai_reader_invoke(action, payload_json)`。 | 命令行执行与跨语言 FFI 调度统一信封返回规范。 |

## 4. 异常处理与系统边界 (Error Handling & Edge Cases)

1. **外部 AI 接口超时与网络离线**：
   - 自动启用指数退避重试（最多 3 次）；
   - 超时或网络离线时，自动切换至离线确定性启发式思维卡片生成，保证服务 100% 可用。
2. **损坏或非标准编码文档**：
   - 自动尝试 UTF-8、GB18030、ISO-8859-1 等多重编码回退解码；
   - 格式损坏文档返回明确错误码 `50001` 与结构化错误描述，避免进程崩溃。
3. **高并发读写与数据安全性**：
   - SQLite 开启 WAL (Write-Ahead Logging) 模式与短重试等待锁；
   - 涉及批注与书籍解构的写入操作采用原子事务。

## 5. 完成定义与验收准则 (Definition of Done - DoD)

1. **功能完备度**：功能矩阵 F-01 至 F-08 全部实现并通过自动化测试；
2. **核心覆盖率**：六元组标准化运行时设计规范（主方法、降级、补偿、度量、回调）单元测试分支覆盖率 ≥ 85%；
3. **纯净无 UI 依赖**：代码库与依赖项零图形库（无 GTK/Flutter/Qt 等），可独立在 Headless Linux 环境下运行；
4. **质量门禁**：通过 `verify_consistency.py` 自动化三文件与索引门禁检查。
