## 1. 产品愿景与定位 (Vision & Value Proposition)

AI Reader 定位于**面向长篇技术文档、论文与专业书籍的高性能、跨平台（Windows, macOS, Linux, iOS, Android 5端）、极简沉浸式 AI 认知阅读器**。

产品深度贯彻 **iA Writer 极简主义排版哲学** 与 **本地优先（Local-First）离线计算** 理念，将强大的本地知识解构引擎与纯净无干扰的阅读心流体验深度融合：
- **排版优先与视觉宁静 (Typography-first)**：借鉴 iA Writer 设计美学，消除密集工具栏与非必要按钮，正文定宽黄金版心居中，顶栏与边框自动隐退；
- **段落级聚焦模式 (Focus Mode)**：阅读与伴读时，当前段落保持 100% 极高清晰度，上下文段落柔和弱化至 65% 透明度，彻底消除视觉分散；
- **划词即伴读与原位追问**：划选段落原地弹出悬浮胶囊，直通 4 大认知模板（⚡️通俗解读、🔗逻辑链条、🧐批判审视、📖术语拆解）；侧栏抽屉（移动端 Bottom Sheet）流式呈现，支持卡片内原位追问并一键存为段落边注；
- **全格式统一结构化解析**：PDF、EPUB、Markdown、TXT 统一解构为结构化 Document AST 语义流，保留精确坐标锚点与字符偏移；
- **离线三级概念拓扑与知识导图**：本地离线计算全文/章节/句子级关键词（TF-IDF + TextRank）与 PMI 概念共现拓扑，秒级生成层级思维导图；
- **Flutter 跨平台 5 端自适应**：桌面端提供左右可折叠的三栏沉浸工作台，移动端提供平滑单栏长文流与触控半屏 Bottom Sheet，全端基于标准六元组 C-ABI FFI 桥接统一调用底层计算引擎。

## 2. 目标用户与使用场景 (Target Users & Scenarios)

### 2.1 目标用户画像
1. **深度研究者 / 技术极客 / 学者**：
   - 核心诉求：在高强度研读论文、技术规范与专业专著时，不被打扰，享受纯粹排版；在遇到难点时能一键获得深层逻辑推演与术语解构。
2. **知识工程师 / 严肃读者**：
   - 核心诉求：多设备（桌面办公 + 移动端通勤）无缝阅读长文，本地离线沉淀高价值批注与知识导图，数据完全私有。
3. **上层应用架构师 / 开发者**：
   - 核心诉求：引擎层与 UI 层高度解耦，通过统一六元组 FFI 桥接协议在 5 端灵活运行。

### 2.2 核心业务场景与操作链路
- **场景 1（沉浸阅读与焦点弱化）**：用户打开书籍 -> 顶部操作栏平滑隐退 -> 开启 Focus Mode 时当前段落 100% 对比度，周围淡化至 65%。
- **场景 2（划词极简伴读与流式洞察）**：选中正文句子 -> 原地悬浮极简药丸 `[⚡️/🔗/🧐/📖]` -> 点击后右侧抽屉（或移动端 Bottom Sheet）以 TTFT < 800ms 流式输出深度洞察。
- **场景 3（原位追问与边注归档）**：在伴读卡片底部输入追问细节 -> 流式追加答复 -> 点击 `[💾 存为边注]` 原子写入本地 SQLite。
- **场景 4（知识导图与拓扑导航）**：展开左侧抽屉 -> 查阅基于 AST 与 PMI 拓扑生成的层级知识树 -> 点击节点精准跳转到正文锚点。
- **场景 5（全平台自适应流转）**：桌面端使用三栏多窗格工作台，移动端使用手势下滑即关的 Bottom Sheet，两端数据通过本地 SQLite 保持一致。

## 3. 功能矩阵规格说明 (Feature Matrix & Functional Specs)

| 模块编号 | 功能模块 | 核心能力描述 | 关键性能与接口指标 |
|---|---|---|---|
| **F-01** | **全格式统一解析引擎** | 统一支持 PDF、EPUB、Markdown、TXT 格式；解构为统一 Document AST，提取章节、段落、样式与嵌入媒体信息。 | 10 万字文档冷启动解构 < 1.5 秒；内存占用 < 50MB。 |
| **F-02** | **结构化段落分块与空间定位** | 将文档文本切分为章节与句子节点；精确记录段落索引、页码跨度与字符偏移量。 | 准确率 100%；支持大文本流式惰性切片。 |
| **F-03** | **批注与边注数据管理** | 支持段落锚点绑定、颜色标识、样式类型、笔记正文及关联 AI 伴读内容的持久化存储与检索；支持 Markdown 格式笔记导出。 | 原子事务写入；100% 增量保存无数据丢失。 |
| **F-04** | **深度认知伴读与模板编排** | 4 大认知伴读模板（通俗化、逻辑链、批判性、术语拆解）；流式组装上下文，支持指数退避重试与离线启发式降级。 | TTFT < 800ms；离线降级响应 < 10ms。 |
| **F-05** | **离线三级 NLP 概念图谱计算** | 本地离线全量计算：全文级/章节级/句子级关键词提取（TF-IDF + TextRank）；词间共现矩阵与 PMI 关联分析。 | 纯本地离线计算，零外部 API 依赖；10 万字图谱构建 < 200ms。 |
| **F-06** | **结构化知识导图生成** | 结合文档目录 AST 与章节级核心词，自动提取全书知识树与多级导图节点。 | 节点秒级生成，提供标准树状 JSON 数据结构。 |
| **F-07** | **本地持久化与 WAL 事务** | 基于 SQLite 数据库；记录书籍元数据、章节、句子、关键词拓扑、思维导图、批注与问答历史；支持审计字段与版本并发控制。 | WAL 模式；零网络依赖；崩溃自恢复。 |
| **F-08** | **CLI 命令行与六元组 FFI 接口** | 提供跨平台终端 CLI 工具（`ai_reader`）与统一信封格式的 C-ABI FFI 函数 `ai_reader_invoke(action, payload_json)`。 | 命令行执行与跨语言 FFI 调度统一信封返回规范。 |
| **F-09** | **极简沉浸式阅读器与 Focus Mode** | 遵照 iA Writer 规范：定宽黄金版心（680px~720px），段落级柔和失焦弱化（当前段 100%，其余段 65% 透明度），全键盘快捷键，顶栏自动隐退。 | 60fps 丝滑滚动；按 Esc 或快捷键 100ms 内完成平滑淡化过渡。 |
| **F-10** | **划词伴读胶囊与原位追问抽屉** | 原地悬浮圆角药丸直达 4 模板；右侧抽屉流式呈现；卡片内单行追问输入，上下文连续；一键持久化边注。 | 选词唤出延迟 < 50ms；抽屉展开不挤压中央阅读版心。 |
| **F-11** | **Flutter 5 端跨平台自适应工作台** | 支持 Windows、macOS、Linux 桌面端（三栏平滑折叠）与 iOS、Android 移动端（单栏全屏 + 手势 Bottom Sheet）。 | 全平台同一套 Flutter 代码与原生 FFI 绑定；手势下滑即关。 |

## 4. 异常处理与系统边界 (Error Handling & Edge Cases)

1. **外部 AI 接口超时与网络离线**：
   - 自动启用指数退避重试（最多 3 次）；
   - 超时或网络离线时，自动切换至离线确定性启发式思维卡片生成，保证服务 100% 可用。
2. **损坏或非标准编码文档**：
   - 自动尝试 UTF-8、GB18030、ISO-8859-1 等多重编码回退解码；
   - 格式损坏文档返回明确错误码 `50001` 与结构化错误描述，避免进程崩溃。
3. **超长篇幅渲染与内存控制**：
   - 移动端与桌面端采用虚拟化列表（Virtual Scroll / ListView.builder）按需惰性渲染段落，内存常驻稳定在 80MB 以下。
4. **高并发读写与数据安全性**：
   - SQLite 开启 WAL 模式；批注与书籍解构的写入操作采用原子事务。
